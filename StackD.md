# Stackd AI 📂⚡
> Gestión inteligente de documentos para emprendedores y equipos en crecimiento.

---

## 🚀 ¿Qué es Stackd?

**Stackd** es una plataforma de gestión documental impulsada por IA, diseñada para PYMEs y emprendedores que están cansados de perderse entre archivos, carpetas y el caos. Convertimos tu desorden documental en un flujo de trabajo inteligente, buscable y automatizado — en minutos.

---

## 🎯 El Problema

- Documentos dispersos entre correo, Drive, Dropbox y WhatsApp
- Horas perdidas buscando contratos, facturas e informes
- Sin control de versiones, sin historial, sin tranquilidad
- Las herramientas existentes están hechas para grandes empresas — no para ti

---

## ✅ La Solución

Stackd lleva la IA a tu stack documental para que puedas:

- 📥 **Capturar** — Sube o conecta documentos desde cualquier fuente
- 🧠 **Comprender** — La IA lee, etiqueta y categoriza automáticamente
- 🔍 **Encontrar** — Busca por contenido, no solo por nombre de archivo
- ⚙️ **Automatizar** — Dispara flujos de trabajo según el tipo o contenido del documento
- 🔒 **Proteger** — Historial de versiones, control de acceso y registros de auditoría

## 🛠️ Stack Tecnológico (Propuesto)

| Capa | Tecnología |
|---|---|
| Frontend | Blazor (ASP.NET Core) |
| Backend | ASP.NET Core Web API (.NET 10) |
| IA / LLM | Claude API (Anthropic) |
| Almacenamiento | AWS S3 / Supabase |
| Base de Datos | PostgreSQL |
| Autenticación | Clerk / Auth0 |
| Hosting | Azure App Service + Azure Static Web Apps |
